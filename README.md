# 카츠 탐방 노트 (안드로이드 설치형 웹앱)

폰 크롬에서 "앱 설치"를 누르면 홈 화면에 아이콘이 생기고, 인터넷 없이도 열려요.
기록과 사진은 **이 폰 안에만** 저장돼요. 파일을 올리는 사이트에는 앱 파일만 올라가고 기록은 올라가지 않아요.

## 파일 5개
- index.html : 앱 본체
- sw.js : 인터넷 없이 열리게 해주는 파일
- manifest.webmanifest : 앱 이름과 아이콘 설정
- icon-192.png, icon-512.png : 아이콘

## 설치 방법 (GitHub Pages, 무료, 약 10분)
1. github.com 에 로그인 (없으면 가입)
2. 오른쪽 위 **+ → New repository**
   - 이름: katsu-note
   - **Public** 선택 → Create repository
3. 만들어진 화면에서 **uploading an existing file** 클릭
4. 압축을 푼 **파일 5개**를 끌어다 놓고 → 아래 **Commit changes**
   (폴더째 말고 파일 5개만 올려요)
5. **Settings → Pages** 로 이동
   - Source: Deploy from a branch
   - Branch: **main** / (root) → **Save**
6. 1~2분 뒤 같은 화면에 주소가 떠요.
   예: https://내아이디.github.io/katsu-note/
7. **안드로이드 폰 크롬**으로 그 주소를 열고
   - 목록 화면의 **설치** 버튼을 누르거나
   - 크롬 오른쪽 위 **⋮ → 앱 설치(또는 홈 화면에 추가)**
8. 홈 화면의 "카츠노트" 아이콘으로 열면 끝!

## 쓰다가 알아두기
- 앱을 지우거나 폰을 바꾸기 전에 목록 아래 **백업 저장**을 눌러 파일로 보관하세요.
  새 폰에서는 **백업 불러오기**로 되돌려요.
- 앱 파일을 고쳐서 다시 올렸는데 폰에 반영이 안 되면, sw.js 맨 위의 `katsu-note-v1` 을 `v2` 로 올려서 다시 올려주세요.
- 사진은 가로세로 1100px 이하로 줄여서 저장돼요.
